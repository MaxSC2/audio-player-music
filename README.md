# Audio Player — локальный музыкальный плеер

**Flutter-приложение для проигрывания локальной музыки на Android.**

## О проекте

Минимальный MVP музыкального плеера, который сканирует устройство, показывает библиотеку треков и умеет их проигрывать. Без стриминга — только локальные файлы.

## Функции

- Сканирование музыкальной библиотеки устройства
- Проигрывание аудиофайлов (just_audio)
- Разрешения на чтение хранилища
- Material Design тёмная тема

## Технологии

- Flutter (Dart)
- just_audio — аудиоплеер
- on_audio_query — сканирование библиотеки
- permission_handler — разрешения Android
- Provider — состояние

## Структура

```
lib/
  models/       — модели данных
  providers/    — состояние (ChangeNotifier)
  screens/      — экраны (Library, Player, etc.)
  ui/           — переиспользуемые виджеты
  widgets/      — мелкие компоненты
SPEC.md         — спецификация проекта
```

## Запуск

```bash
cd /sdcard/projects/audio_player
flutter run
```

## Статус

MVP. Рабочее сканирование библиотеки и базовая навигация.
